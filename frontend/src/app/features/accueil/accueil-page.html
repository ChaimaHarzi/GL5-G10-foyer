Gestion des foyers universitaires

Interface Angular de l’API Spring Boot tpFoyer : universités, foyers, blocs, chambres, étudiants et réservations.

Pour commencer

  1. Créer une université et un foyer, puis affecter le foyer à l’université.
  2. Créer des chambres et un bloc, puis ranger les chambres dans le bloc.
  3. Créer des étudiants, puis leur réserver une place dans le bloc.
